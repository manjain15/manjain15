## Projects

### [Jarvis](https://github.com/manjain15/jarvis)
A personal assistant that runs my day as a student. It plans study blocks around my timetable, writes them to Google Calendar, and checks what actually happened against real data (Hevy workouts, Google Health steps, calendar, phone events) instead of asking me.

- Built around a loop: **commit → verify → escalate → adapt**
- Python computes every number; Claude only writes short prose, so briefs stay trustworthy and cheap
- Runs on a small VPS at about $3 a month in API costs, with ~400 tests and push-to-deploy via GitHub Actions
- Telegram, email and agent-API channels, with a file-locked daily ledger as the source of truth

### [ViewTrip v2](https://github.com/manjain15/viewtrip-v2)
A Sydney public transport trip planner, rewritten from my Year 12 major project ([original](https://github.com/manjain15/Manav-Jain-Major-Project)) with a cleaner architecture and a web UI.

- Async client for the Transport for NSW APIs, SQLite-backed saved trips, cached GTFS stop search
- FastAPI + HTMX front end, 49 tests with a mocked API
- Fixed a timezone bug from v1 by handling Sydney/UTC conversion in one place
